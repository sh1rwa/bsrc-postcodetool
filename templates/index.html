How to use this tool

Basic usage

  • Enter one or more postcodes into the box below
  • Separate postcodes using commas or new lines
  • Click Lookup to find the corresponding ward
  • Invalid inputs will be highlighted with suggestions where possible
  • Duplicate postcodes are supported

Additional features

  • Use Show/Hide Chart for a bar chart breakdown by ward
  • Use Filter to select specific wards or toggle invalid/not found rows
  • Click Save CSV to export results for use in Excel
  • Click Save Chart to download the chart with counts
  • Click Reset to default in the filter menu to restore all wards
⚠  'Invalid' or 'Not Found' postcodes are highlighted in the table but are excluded from charts and CSV exports.
